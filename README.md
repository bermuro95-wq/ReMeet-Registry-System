> *"Reuniting families, restoring hope, and connecting loved ones across borders."* ✨

Welcome to **ReMeet-Registry-System** (The ReMeet Global Connection Registry)—a structured web application and centralized database platform designed to facilitate missing persons registration, community-driven reporting, and family reunification efforts.

---

## 🌟 The Story Behind the Project

When loved ones go missing due to displacement, migration, or unforeseen crises, fragmented records and disconnected communication channels make searching overwhelming. 

**ReMeet** was built to bridge that gap. By providing a reliable, accessible, and structured global registry powered by modern cloud database infrastructure, ReMeet enables families, humanitarian responders, and communities to log detailed missing person profiles, search verified records, and coordinate safe reconnections.

---

## ✨ Key Features & Experience

* **📋 Structured Missing Persons Registration:** Intuitive, standardized intake forms to document vital identification details, last-known locations, physical descriptions, and contact records.
* **🔍 Smart Search & Directory Filtering:** Fast, real-time querying across the registry by name, region, age group, or registration date to help families locate matches quickly.
* **🗄️ Cloud-Backed Data Integrity:** Powered by Supabase PostgreSQL database infrastructure for secure storage, structured relational indexing, and reliable uptime.
* **📸 Photo & Media Verification:** Support for uploading identification photographs and visual markers to assist community recognition.
* **🤝 Tip & Sighting Submission:** Dedicated communication workflows allowing community members to submit verified leads or sighting reports safely.
* **📱 Responsive & Accessible UI:** Clean, distraction-free interface optimized for both desktop and mobile devices so users can access the registry anywhere.

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3 (Responsive Grid/Flexbox layouts), Vanilla JavaScript (ES6+)
* **Backend & Database:** Supabase (PostgreSQL Database, Authentication, Storage Buckets, Real-time APIs)
* **Icons & Typography:** Font Awesome Icons, Google Fonts
